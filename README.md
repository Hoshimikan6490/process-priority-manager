# Process Priority Manager
## 概要
このプログラムは、ユーザーが入力したプロセス名のプロセスを検索し、優先度(Priority)を変更するアプリケーションです。

## 機能
- プロセス名を指定して、それが含まれるプロセスの優先度を最優先（リアルタイム）に変更する。
- プロセス名を入力することで、該当するプロセスを検索する機能
- スタートアップ起動・バックグラウンド起動により、常にプロセスを監視して優先度を調整する機能
- 登録済みの優先度設定ごとの有効/無効切り替え（スライドスイッチ・チェックした項目の一括有効化/無効化/削除）
- 新バージョンの自動確認と、ダウンロード＆インストール（GitHub Releasesの `.msi` を使用。設定画面の「今すぐ更新を確認」からも実行可能）

## 設定
- ホワイトテーマ/ダークテーマ設定
  - ホワイトテーマ
  - ダークテーマ
- スタートアップ起動設定
  - スタートアップ起動する
  - スタートアップ起動しない
- システムトレイ常駐設定（既定: ON。起動時からトレイにアイコンを表示し、×ボタンでトレイに格納）
  - バックグラウンド起動する
  - バックグラウンド起動しない
- プロセス一覧更新間隔設定
  - 1 秒 1 回
  - 5 秒に 1 回
  - 10 秒に 1 回
  - 20 秒に 1 回
  - 30 秒に 1 回
  - 検索キーワードが更新された時のみ
- 優先度更新頻度設定
  - 毎秒 1 回
  - 5 秒に 1 回
  - 10 秒に 1 回
  - 20 秒に 1 回
  - 30 秒に 1 回
  - 45 秒に 1 回
  - 60 秒に 1 回
  - 初回のみ

## インストールなどについて
### 通常インストール
Releasesにあるデータを使用してください

### 開発者インストール
開発用に依存関係をインストールする場合は以下のコマンドを利用すればインストールが可能です。
```
pip install -r requirements.txt
```
MSIインストーラーは以下のコマンドでbuild出来ます（uv、およびWiX Toolset v4以降 + `WixToolset.UI.wixext` が必要です）。
```
python installer/build_msi.py
```
`appdist/windowsmsi/dist/` にMSIが出力されます。

#### インストーラーの流れ・選択できる項目
ようこそ → 使用許諾契約 → インストール範囲 → インストール先 → 更新設定 → インストール
- 現在のユーザー向け / すべてのユーザー向け（インストール範囲）
- インストール先フォルダー（ドライブ）
- 更新の定期確認（GitHub Releases）のチェック有無（アプリの設定画面からも変更可能）

使用許諾契約の本文は `installer/license.rtf` です。WordPad等で編集してから再ビルドしてください。

サイレントインストール例: `msiexec /i <msi> /qn APPLICATIONFOLDER=D:\Apps\PPM CHECKUPDATES=0`（`CHECKUPDATES=0` で更新確認なし、省略で更新確認あり。全ユーザー向けは `ALLUSERS=1`）。
